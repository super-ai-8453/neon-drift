An endless arcade dodger in a single HTML5 canvas. Steer a neon ship through
falling debris, collect multipliers, and survive a difficulty curve that keeps
tightening. Everything is drawn procedurally: no images, no webfonts, no
dependencies.

## Run it

```sh
node --experimental-strip-types main.ts
```
